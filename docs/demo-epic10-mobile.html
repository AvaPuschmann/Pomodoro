Setup — Préparer les données

  1. Lancer l'app via Run ▶ (pas Debug 🐞), compte connecté.
  2. Aller dans l'onglet Planner.
  3. Ajouter 4 tâches :
    • Rédiger rapport → 3 🍅
    • Call client → 0 🍅 (tâche sans pomodoro)
    • Relecture slides → 2 🍅
    • Réunion équipe → 0 🍅 (tâche sans pomodoro)
10-4

Heure de fin de journée estimée

Scénario — Affichage et réactivité

  1. Observer le header du Planner, sous "Day Planner · X/12 🍅".
  2. VÉRIFIER Le label "Fin de journée estimée : HHhMM" est visible.
  3. Réduire les 🍅 de "Rédiger rapport" de 3 → 1 avec le bouton −.
  4. VÉRIFIER L'heure recule (moins de travail = fin plus tôt).
  5. Remettre à 3 🍅.
  6. VÉRIFIER L'heure avance à nouveau.
  7. Cocher "Relecture slides" comme terminée (voir story 10-3).
  8. VÉRIFIER L'heure recule de ~55 min (2 🍅 + 1 pause de moins).
"Je sais en un coup d'œil si ma journée est tenable, sans calcul mental."
10-3

Checkbox de complétion déclarative

Scénario A — Tâche sans pomodoro (Call client)

  1. Repérer "Call client" (0 🍅) — impossible à compléter via le timer.
  2. Appuyer sur le cercle ☐ à gauche du bouton ▶.
  3. VÉRIFIER La tâche bascule instantanément dans la section Terminées avec le cercle vert ✓.
  4. VÉRIFIER "Fin de journée estimée" ne change pas (0 🍅 = pas de coût temps).
  5. Appuyer à nouveau sur le ✓ dans la section Terminées.
  6. VÉRIFIER La tâche remonte dans la section active.

Scénario B — Tâche avec pomodoros (Relecture slides)

  1. Appuyer sur ☐ de "Relecture slides" (2 🍅).
  2. VÉRIFIER La tâche passe en Terminées.
  3. VÉRIFIER L'heure de fin de journée recule (2 🍅 de moins ≈ −55 min).
  4. Fermer l'app et la relancer.
  5. VÉRIFIER La tâche reste cochée après redémarrage (persistance Room DB).
  6. Décocher → la tâche revient dans les actives, l'heure avance à nouveau.
"Les meetings et appels peuvent enfin être cochés sans lancer un timer."
10-2

Heure de fin estimée sur le Timer

Scénario — Activation depuis le Planner

  1. Appuyer sur ▶ de "Rédiger rapport" (3 🍅) dans le Planner — l'app bascule sur l'onglet Timer.
  2. NOTER Pas de label "Fin estimée" tant que le timer est en pause.
  3. Appuyer sur ▶ (Play) pour démarrer.
  4. VÉRIFIER Le label "Fin estimée : HHhMM" apparaît sous le compte à rebours.
  5. Appuyer sur ✓ Valider ce pomodoro.
  6. VÉRIFIER Pendant la pause SHORT_BREAK, "Fin estimée" reste visible et recule légèrement (1 pomo de moins).
  7. Appuyer sur ⏸ Pause.
  8. VÉRIFIER "Fin estimée" disparaît.
  9. Relancer le timer avec 1 seul 🍅 restant.
  10. VÉRIFIER Fin estimée = maintenant + secondes restantes (pas de pause ajoutée après le dernier pomo).
"Je sais exactement à quelle heure je terminerai cette tâche — je peux placer une réunion sans hésiter."

Critères de validation — Definition of Done

# Story Critère OK ?
1 10-4 "Fin de journée estimée" visible dès qu'il reste des 🍅
2 10-4 EoD se met à jour en temps réel quand on modifie les 🍅
3 10-4 EoD disparaît quand toutes les tâches sont cochées / terminées
4 10-3 Checkbox visible sur toutes les tâches (actives + terminées)
5 10-3 Coche → section Terminées immédiatement, sans rechargement
6 10-3 Décoche → section active immédiatement
7 10-3 Tâche cochée persiste après fermeture / réouverture de l'app
8 10-2 "Fin estimée" visible pendant FOCUS et SHORT_BREAK
9 10-2 "Fin estimée" absente quand timer idle ou en pause
10 10-2 Valeur correcte : dernier pomo = now + secondes restantes (pas de break)
11 — Aucun crash, aucune erreur console pendant toute la démo
